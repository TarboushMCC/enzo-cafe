# Enzo Café

A cinematic website concept for a high-end café and dessert house — designed to feel like walking through the space, not reading a brochure.

> **Note:** This repository currently contains documentation only. The source code will be published at a later date. Concept/passion project — not affiliated with a real business.

## Experience

- Loading screen into an animated hero
- Interior and dessert "experience" sections built as scroll-driven scenes
- Signature drinks showcase, experience timeline, testimonials
- Instagram feed section and a reservation flow
- Smooth scrolling throughout via Lenis, with a custom scroll provider

## Tech stack

| Layer | Choice |
|---|---|
| Framework | Next.js 16 (App Router), React 19 |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| Animation | Framer Motion 12 |
| Scrolling | Lenis smooth scroll |
| Icons | Lucide |
